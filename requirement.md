# Requirements & Evaluation

Your solution will be evaluated based on the following criteria. Projects must demonstrate both technical excellence and creative innovation:

## Core Requirements

### 1. GitHub Copilot Usage
Your project must demonstrate meaningful use of GitHub Copilot during development. This includes:
* Using Copilot suggestions to accelerate code writing.
* Leveraging Copilot Chat for problem-solving, debugging, or code explanation.
* Documenting how Copilot assisted in your creative process.

### 2. Microsoft IQ Integration
Your project must integrate at least one Microsoft IQ intelligence layer. Choose whichever fits your project best:
* **Foundry IQ:** Agentic knowledge retrieval for AI agents. Connects multiple enterprise sources, enforces permissions, and delivers cited, grounded answers to reduce hallucination.
* **Work IQ:** The intelligence layer behind Microsoft 365 Copilot. Builds memory from emails, meetings, chats, and documents to understand work context, people, and relationships.
* **Fabric IQ:** Semantic intelligence layer for Microsoft Fabric. Uses ontologies and knowledge graphs to give business meaning to enterprise data, enabling AI agents to reason over real business concepts.

### 3. Creative Application
Your submission must be a creative application that showcases innovation and imagination. The application should:
* Demonstrate a unique or novel concept.
* Provide value, entertainment, or utility to users.
* Show thoughtful design in user experience.
